论文阅读 — Human Fall Detection Using Pose Estimation

发表于2026-07-30|更新于2026-08-07
|字数总计:2.3k|阅读时长:8分钟|阅读量:

论文信息

  • 标题: Human fall detection using pose estimation: From traditional machine learning to vision transformers
  • 作者: Ali Raza, Muhammad Haroon Yousaf, Waqar Ahmad, Sergio A. Velastin, Serestina Viriri
  • 单位: 巴基斯坦塔克西拉工程大学 / 伦敦玛丽女王大学 / 西班牙马德里卡洛斯三世大学 / 南非夸祖鲁-纳塔尔大学
  • 期刊: Engineering Applications of Artificial Intelligence, 143 (2025) 109809（Elsevier，CC BY-NC-ND 开放获取）
  • 关键词: 跌倒检测、人体姿态估计、机器学习、深度学习

一句话总结

本文系统对比了 5 种姿态估计器 × 8 种分类网络在 UR-Fall / UP-Fall / Le2i 三个跌倒检测数据集上的组合效果，证明基于骨架的姿态估计 + 视觉 Transformer 既能保护隐私，又能达到超越 SOTA 的检测精度。

研究背景

  • WHO 报告全球每年约 3730 万人因跌倒受伤，跌倒是老年人受伤和死亡的主因之一。
  • 可穿戴传感器（腕带、项链等）存在佩戴不适、需频繁充电、成本高等问题。
  • 视觉方案更自然：仅用视频帧识别跌倒，无需任何穿戴设备。
  • 关键洞察：基于人体骨架点（skeleton keypoints）的方法比像素级方法更具优势——
    • 隐私保护：只保留骨骼点、隐藏 RGB 图像，适合卧室/浴室/厨房等敏感场景
    • 训练更快：骨架数据维度远低于图像
    • 更鲁棒：对模糊、光照变化、遮挡更不敏感

方法

整体框架

论文提出两条处理流水线，仅使用单摄像头即可完成跌倒检测：

Pipeline A：姿态估计器（AlphaPose / OpenPose / BlazePose / OpenPifPaf / HRNet）提取骨架 → 骨架特征 → 分类网络（ML 分类器 / RNN / LSTM / ST-GCN / ViT）→ 跌倒识别。

Pipeline B：使用 Transformer 姿态估计（ViTPose / TransPose）提取骨架，再配合 Transformer 网络进行分类，是论文的创新方向。

姿态估计器

论文横向对比了 5 种经典的姿态估计方法，输出的骨架点数各不相同：

姿态估计器 骨架点数 特点
AlphaPose 17 多人体姿态估计，依赖人体检测器（如 YOLO），COCO 上 mAP 70%
OpenPose 25 CMU 出品，基于 PAF + 置信图，实时多人检测
BlazePose 33 MediaPipe 系列，先用分割掩码分离背景再回归关键点
OpenPifPaf - 复合场建模关键点的时空关联，支持实时追踪
HRNet - 全程保持高分辨率表示，关键点定位精度高

方法 1：机器学习分类器 + 滑动窗口

将每帧的骨架关键点作为特征，用滑动窗口（窗口大小 = 帧率 × 秒数）把连续帧打包成一个序列样本，送入 SVM / KNN / MLP / 随机森林 分类。

方法 2：RNN 与 LSTM

把骨架序列（24 帧为一组，16 维姿态向量）输入循环神经网络。最优配置为 10 层 LSTM、80 个隐藏单元，配合批归一化层提升训练稳定性。

方法 3：ST-GCN（时空图卷积）

ST-GCN 同时建模关节点之间的空间关系（人体骨架的图结构）和时间演化（跨帧），10 层网络、卷积核大小 9，使用残差连接与 Dropout 防止过拟合。

方法 4：Vision Transformer

将骨架序列编码为 [序列长度, 批量大小, 512维] 的张量，送入多头自注意力编码器，捕获长距离的时空依赖，最后用线性层分类跌倒/正常。

关键预处理：相对位置归一化（RP Normalization）

针对姿态估计器容易产生的关键点缺失问题，论文提出两步预处理：

  1. 相对位置归一化：以髋关节中心为参考点，把所有关键点坐标位移到图像中心对齐。保留原始数据分布，且无需同时计算缺失点。
  2. 线性插值：对缺失的关键点用已知邻近点插值补全。

效果显著：缺失关键点比例从原始的 22.38% → RP 归一化后 13.4% → 插值后再降至 **1.8%**。冗余关节（与跌倒判别无关的关节点）也被剔除，仅保留鼻、肩、肘、腕、颈、髋、膝、踝等关键点。

Transformer 姿态估计器（论文亮点）

论文把视觉 Transformer 同时用在姿态提取端和分类端：

  • TransPose：CNN（ImageNet 预训练）提取底层特征 → Transformer Encoder 交互空间/特征信息 → Head 网络预测热图。

  • ViTPose：CNN 定位人体 → Patch Embedding → 多层多头自注意力 + 前馈网络 → 回归骨架关键点。

数据集

数据集 规模 内容
UR-Fall 70 段跌倒序列 5 人、双 Kinect + 蓝牙惯性传感器，日常环境
UP-Fall 17 人 × 12 种动作 5 种跌倒 + 7 种日常动作
Le2i 191 个视频 家/咖啡馆/工作场所/学校 4 种场景，存在光照和遮挡变化

训练/测试按 70% / 30% 划分，并采用 10 折交叉验证。

消融与要点分析

  1. 数据增强 / 预处理的收益：RP 归一化 + 线性插值将缺失关键点从 22.38% 降到 1.8%，是精度的关键保障。
  2. 骨架方法 vs 像素方法：骨架方法在遮挡、光照变化下更鲁棒，且训练成本更低。
  3. 隐私优势：只需骨架点即可完成检测，无需暴露真实人物影像，契合卧室、卫生间等隐私敏感场景。
  4. 计算开销：Vision Transformer 训练/推理算力需求大，在资源受限的边缘设备上部署受限，这也是论文展望未来要做边缘计算优化的原因。

个人总结

贡献亮点：

  • 论文做了非常全面的系统性对比实验：5 种姿态估计器 × 8 种分类架构 × 3 个数据集，覆盖面广、结论清晰，是很好的”选型参考”。
  • 把 ViTPose / TransPose 引入跌倒检测，验证了视觉 Transformer 在姿态提取端和分类端的可行性，贴合深度学习前沿趋势。
  • 预处理细节做得好：相对位置归一化 + 缺失关键点线性插值，解决了下游任务中容易忽略的”数据质量问题”。

局限与思考：

  • 数据集都是室内单人、摆拍场景（论文自己承认），与真实世界多人、多变场景还有差距，实用性仍需验证。
  • Vision Transformer 方法在该任务上精度并没有显著碾压 ST-GCN / RNN（甚至略低），说明任务的复杂度还不足以完全发挥 Transformer 的优势，性价比不如轻量方案。
  • 缺少推理速度 / 参数量等工程维度对比，作为”部署选型”参考还不够完整。

启发：

“用骨架数据 + 轻量分类器达到接近深度模型的精度”这一思路对嵌入式 / 实时场景很有价值。对我而言，后续做相关任务时，先想清楚数据质量问题（关键点缺失、遮挡），再考虑模型架构，这个顺序可能更重要。
